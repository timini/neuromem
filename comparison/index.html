    Comparison with other memory systems¶

    How does neuromem compare with published memory systems on LongMemEval? The short answer is that no two rows of any public LongMemEval table were measured the same way, so the comparison is a rough placement, not a ranking.

    Where neuromem sits¶

    neuromem configuration Accuracy Sample Answer model Judge
    Episodic memory (partial run) 0.938 (15/16) 16 instances that finished before the spend cap: 6 multi-session, 3 knowledge-update, 3 single-session-user, 2 temporal, 1 assistant, 1 preference gemini-3.8-flash Official per-type prompts on gemini-3.8-flash
    Tag-graph memory, same 16 instances 0.750 (12/16) as above gemini-3.8-flash as above
    Tag-graph memory 0.746 (44/59) 10 per type, seed 42 gemini-3-flash-preview Official per-type prompts on gemini-3.8-flash

    Differences from the official protocol, which every comparison below should account for:

    • Sample. neuromem's numbers come from 60 questions (10 per type) or fewer, not all 500. The six types are equally weighted, which matches the "unweighted mean of six types" some vendors report, not question-weighted accuracy over 500 questions (where single-session-user and multi-session dominate).
    • Judge. The prompts are the official ones, but the judge is gemini-3.8-flash, not gpt-4o-2024-08-06. Changing only the judge model moved the tag-graph score by about one question in 59.
    • Answer model. gemini-3.8-flash is a 2026 model. The official baselines use gpt-4o (2024). The table below shows the answer model alone moving a system by more than 10 points.
    • Interval. 15 of 16 has a 95% interval of 0.72 to 0.99.

    The episodic result is 16 instances, not stratified by type (6 of the 16 are multi-session), so it cannot yet be placed against any row below. The tag-graph result (0.746 on a balanced 59) is a rough match for the mid-table systems in shared-protocol re-runs. A full 500-question run with the official GPT-4o judge would be needed to place it properly.

    Reading the table¶

    These numbers do not form one leaderboard. The answer model alone moves a single memory system by 10 points or more: Mastra Observational Memory scores 84.23% with gpt-4o and 94.87% with gpt-5-mini, and Hindsight ranges from 83.6% to 91.4%. Judges also differ. The official protocol uses gpt-4o-2024-08-06 with per-type prompts, while other rows use gpt-4o-mini, gpt-4.1-mini, GPT-OSS-120B, Gemini, gpt-5.4, the answering model itself, or a judge they don't name. Mnemon's results show that changing only the grader shifts its score by 1 to 2 points. The way scores are combined also varies: Mastra, SimpleMem and Redis average the six question types without weighting, which gives a different number from per-question accuracy, and one study reports token F1, which cannot be compared with any judged accuracy. Most of the top scores are self-reported by vendors. Shared-protocol re-runs put several of them lower: on OmniMemEval, Zep scores 79.8, Mem0 56.0 and Hindsight 72.2, against self-reported 90.2, 94.4 and 94.6. Part of each gap comes from the weaker common answer model, so it is not all inflation. The dataset variant also matters. The oracle file holds only the evidence sessions and scores much higher (GPT-4o 87.0% on oracle vs 60.6% on S), M is harder, several vendor pages don't say which variant they used, and OmniMemEval uses the cleaned S data released after the 2024 paper results. The ChatGPT/Coze pilot and the Mem-alpha subset use different question sets and histories, so they should not be compared with any S row. The fairest comparisons are within one source that holds the answer model and judge fixed: the Redis table (gpt-4o answering and judging), OmniMemEval (gpt-4.1-mini answering, gpt-4o-mini judging) and EvalMem (gpt-4o-mini answering, gpt-5-mini judging).

    Sources of shared-protocol comparisons¶

    The fairest comparisons hold the answer model and judge fixed across systems:

    • Redis agent memory benchmark: gpt-4o answering and judging.
    • OmniMemEval: gpt-4.1-mini answering, gpt-4o-mini judging, 500 questions.
    • EvalMem: gpt-4o-mini answering, gpt-5-mini judging.
