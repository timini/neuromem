    Decision rules (plan 7.6)¶

    - means the data needed was not available, or (rule 4) that the test cannot fire. Recall rules use session_recall_strict; the plan-wording metric is shown alongside.

    rule session_recall_strict session_recall
    1 flat wins yes yes
    2 unified wins no no
    3 linked views win no no
    4 links matter - -
    4 links matter, B12 recall (descriptive) no no
    5 one view is enough no yes
    5 arms recovering 80% of M's gain SE
    6 tags stay in leaf text yes yes
    • Rule 4 not testable: M and M-nolink reciprocal ranks are identical on every instance, because link following changes only the node pool, not the fused list. See the descriptive B12 recall comparison instead.
